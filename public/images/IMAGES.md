# الصور الحقيقية — كيف تعمل

الموقع يستخدم `next/image` لتحميل صور فوتوغرافية حقيقية لكل قسم، مع رجوع تلقائي
إلى رسمة أنيقة إذا تعذّر تحميل الصورة (حتى لا يظهر أي كسر في التصميم).

## أين تُضبط الصور
كل الصور معرّفة في مكان واحد: `src/config/images.ts`
لكل خانة (slot):
- `remote` — رابط صورة من Unsplash (مجانية الاستخدام) تظهر مباشرة على جهازك.
- `local` — مسار داخل `/public` لو أردت استخدام صورك الخاصة (له الأولوية).
- `alt` — نص بديل للوصول (SEO / قارئ الشاشة).

## لاستخدام صورك الخاصة (موصى به للإنتاج)
ضع ملفاتك بهذه الأسماء داخل `/public` وستُستخدم تلقائياً:

| الخانة | المسار المحلي | المقترح |
| --- | --- | --- |
| البطل (Hero) | `/images/hero/main.jpg` | سيارة فاخرة، لقطة ثلاثية الأرباع، إضاءة نظيفة |
| من نحن | `/images/about/interior.jpg` | مقصورة/تفاصيل داخلية لامعة |
| الباقة المتكاملة | `/images/services/full.jpg` | سيارة كاملة بعد التلميع |
| التنظيف الخارجي | `/images/services/exterior.jpg` | تفاصيل الهيكل/الجنوط |
| التنظيف الداخلي | `/images/services/interior.jpg` | التابلوه/المقاعد |
| تنظيف المحرك | `/images/services/engine.jpg` | حجرة المحرك نظيفة |
| مميزة (Benefits) | `/images/common/detailing.jpg` | لقطة تفصيل قريبة |
| التطبيق | `/images/app/context.jpg` | استخدام الهاتف/الحجز |

مقاس مناسب: عرض 1200–1600px، صيغة JPG/WebP، جودة عالية.
تذكير: الخدمة غسيل **جاف** — تجنّب صور الماء أو الرغوة أو الخراطيم.

## تفعيل/تعطيل الصور البعيدة
افتراضياً الصور البعيدة مفعّلة. لإجبار الاعتماد على الملفات المحلية فقط:
```
NEXT_PUBLIC_USE_REMOTE_IMAGES=false
```
