# صور الموقع

استبدل الصور النائبة (مكوّن `Media`) بصور احترافية حقيقية للغسيل الجاف/التفصيل.
لا تستخدم صوراً بها ماء أو خراطيم أو أنفاق غسيل.

المجلدات:
- hero/ — الصورة الرئيسية والتركيب التحريري
- about/ — قسم من نحن
- services/ — صور الخدمات (full, exterior, interior, engine)
- subscriptions/ — صور الاشتراكات
- app/ — لقطات التطبيق
- reviews/ — صور العملاء (اختياري)
- common/ — عناصر مشتركة
